# Amazon Employee Analytics — SQL Database Project


> **A SQL-based employee analytics project exploring workforce demographics, compensation, experience, skills, work modes, and performance.**

## 📊 Project Overview

This project demonstrates how SQL can be used to organize and analyze employee data and answer real-world business questions.

### 🔍 What This Project Analyzes

* 👥 Employee demographics
* 💼 Departments and job titles
* 💰 Salary and compensation
* 🌍 Country and city distribution
* 🏠 Work modes
* 📈 Years of experience
* 🎯 Skills
* ⭐ Performance ratings
* 📅 Employee joining trends

## 🛠️ Technologies

**SQL • MySQL • Data Analysis • Database Management**

## 📁 Dataset

The database includes:

`Employee_ID` · `Name` · `Gender` · `Age` · `Country` · `City` · `Work_Mode` · `Salary` · `Department` · `Job_Title` · `Years_Of_Experience` · `Joining_Date` · `Skill` · `Performance_Rating`

## 💡 Business Questions

This project can answer questions such as:

* Which department has the highest average salary?
* Which job titles have the most employees?
* How does experience relate to salary?
* Which cities and countries have the most employees?
* Which skills are most common?
* Which departments have the highest performance ratings?

## 🚀 How to Run

1. Open `amazon_employee.sql` in MySQL Workbench.
2. Execute the SQL script.
3. Run the queries to explore the employee data.
4. Analyze the results to identify business insights.
